# 未來時代與世界結局（2026-11-18）

小黑的想法：遊戲不只到現在，要能一路玩到未來（例如 2070 年移民火星），結果依玩家的方向與介入而不同，最後玩到世界毀滅，給一份報告。

## 原則對照

| 原則 | 做法 |
|---|---|
| 數值只能由引擎計算 | 暖化、死亡、火星人口都在 `engine/future-engine.js` 依公式計算；介面只顯示。 |
| 每個變化都要有原因 | 所有死亡經 `Future.kill()` 寫進因果帳（「核子攻擊」「氣候災害」「人造瘟疫」…）；每場災難、里程碑、結局都是事件，附原因。 |
| 可重現 | 未來風險用獨立的種子亂數序列 `w.future.rng`（由世界種子產生），不打亂原本的亂數順序。 |
| 不用固定數值假裝模擬 | 未來科技沒有固定年份；每種風險每年依當時世界的狀態算機率。 |
| 玩家介入要記錄 | 新神之手經 `WorldEngine.divine()` 寫入 commandLog；「如果？」可以阻止任何一場災難。 |
| 係數集中 | `params.future` 與 `params.divine`（aisafety／calm／green），全部示意值。 |

## 機制

- **氣候**：暖化 = 起點暖化 + 係數 × 累積化石燃料使用量（國內化石能源 + 進口能源）。再生能源、核融合提高潔淨能源比例（不受儲量限制、不排放）；碳捕集每年移除一部分累積排放。超過 1.5°C 收成下降（低緯度 ×1.3、高緯度 ×0.6）；超過 2°C 有氣候災害死亡（富國減半）；超過 3°C 每年 2.5% 機率觸發臨界點（+0.4–1.0°C，不可逆）。
- **核武**：核能與火箭普及 ≥ 50% 的國家是擁核國。兩個擁核國交戰、只有一方擁核但戰況危急、或互相敵視（只算最敵對的 3 對，暖化越高越緊張）時，每年有機率動用核武；與交戰方結盟的擁核國有 50% 機率被捲入。直接死亡 10–35%，之後核子寒冬（全球收成 −30% 起，每多一個擁核國再 −15%，最多 −85%，持續 7 年）。
- **人工智慧**：能力 = 人工智慧 1 + 通用 AI 2 + 超級智慧 4；安全 = AI 安全研究 1.5 + 可解釋 AI 3 + 事故教訓 + 神之手 + 可解釋 AI 普及後的持續累積。通用 AI 出現後，每年事故機率 = 1% × 差距²（領先國家打仗或擴張時 ×2）。超級智慧普及後，事故可能變成失控（直接結局）。
- **人造瘟疫**：機率依基因工程、合成生物學普及度、醫療水準、是否有戰爭；嚴重度重尾分布。
- **小行星**：每年 0.025%（遊戲化）；行星防禦普及可以偏轉。
- **火星**：完成「火星殖民」建立殖民地（1,000 人），每年成長 25%（受容量限制，核融合與超級智慧提高容量），100 萬人可自給自足。
- **結局**：地球人口 < 高峰 35% → 文明崩潰，名稱取最近 40 年死亡最多的原因；超級智慧失控直接結束；星際航行 + 火星自給自足 → 發射移民船，150 年後抵達＝好結局。地球毀滅但火星自給自足時，結局文字會寫人類在火星延續。

## 介面

- 總覽「人類的未來」卡片：末日鐘（今年總風險換算，示意）、暖化、擁核國、AI 能力／安全、火星人口、各風險今年的機率。
- 世界結局報告：結局動畫、人口與暖化／風險曲線、關鍵轉折點、災難清單、玩家每一次介入，以及「沒有你的世界」：從起點同種子重跑、不重播玩家政策／神之手／規則／「如果？」，比較結局與年份。

## 災難紀錄與結局說明（2026-11-18 補強）

- 每場災難分成「事件觸發」（為什麼會發生）與「實際造成的變化」（引擎算出的數字）。紀錄 `impact`：災難前世界人口、額外升溫、全球平均收成前後、之後的死亡。
- 氣候臨界點當下沒有直接死亡；之後每年的氣候災害死亡中，「臨界點額外升溫」造成的部分 = 總死亡 ×（1 −（不含臨界點的暖化損失）／（實際暖化損失）），依各次臨界點的升溫比例分給它們；由暖化造成的饑荒死亡也一樣拆分。核子與撞擊寒冬期間的死亡算給造成寒冬的那場災難。
- 嚴重度（輕微／嚴重／重大／毀滅性）只看實際的死亡比例、升溫、收成損失（`params.future.severity`），只用來顯示。
- 結局報告「結局是怎麼發生的」：累積排放 → 暖化與臨界點 → 收成 → 各原因的死亡 → 人口跌破門檻。

## 已知限制

- 係數全是示意值；未來沒有史實可校準，只檢查「量級合理、各種結局都可能出現」。
- 火星殖民地不是國家（不參與外交、戰爭），只是人口與里程碑。
- 長期人口在無災難的世界線會持續成長（8 國劇本 2400 年可達百億以上），之後可考慮加入承載力上限。
