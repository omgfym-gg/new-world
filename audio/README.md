# 背景音樂

| 檔案 | 用途 | 播放時機 |
|---|---|---|
| `calm.mp3` | 「遠古・創世」史詩探索曲 | 平時 |
| `war.mp3` | 「戰場」戰爭曲 | 打開戰場畫面時（關掉視窗後換回平時曲） |

## 來源與授權

- 兩首都是本專案的**原創配樂**，2026-11-18 用小黑電腦上的 **ACE-Step 1.5**（AI 作曲模型，MIT 授權，turbo 模型）生成，只用文字描述，沒有參考或取樣任何現有歌曲。
- 生成後把結尾和開頭交叉淡化 4 秒，做成可以無縫循環的版本，再轉成 MP3。
- 播放程式在 `ui/music.js`：右下角 ♪ 按鈕可開關、調音量（設定記在瀏覽器裡）。瀏覽器規定玩家先點一下畫面才能出聲。
- 音樂只是介面效果，不讀寫任何模擬數值。
