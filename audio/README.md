# 背景音樂

音樂會**隨著世界的科技進步換風格**，越往後越有科技感。每個時代有一組平時曲和一組戰爭曲
（視窗裡有戰場畫面時播戰爭曲），播完一首自動淡入下一首，輪流播放。

## 時代怎麼判斷

只看「世界上已經出現的最先進科技」（`app.js` 的 `musicEra()`，只讀取，不改任何數值）：

| 時代 | 條件 | 平時曲 | 戰爭曲 |
|---|---|---|---|
| 石器時代 | 遠古，還沒有文字 | 營火之夜、狩獵遠行、創世黎明 | 兩軍交鋒、最後防線、戰場 |
| 古文明 | 遠古，已有文字 | 創世黎明、大河文明、帝國榮光、古老星夜、遠古・創世 | 同上 |
| 大航海與啟蒙 | 遠古，已有印刷術、火藥或羅盤 | 航向新大陸、啟蒙之光、帝國榮光 | 同上 |
| 工業時代 | 近代世界 | 蒸汽與鋼鐵、新世紀之城 | 戰壕進行曲、最後防線 |
| 資訊時代 | 已有電子計算 | 電波與晶片、地球村 | 現代戰爭、戰壕進行曲 |
| 未來 | 已有網際網路與人造衛星 | 軌道之上、霓虹文明 | 星際戰火、現代戰爭 |

## 來源與授權

- 全部是本專案的**原創配樂**，2026-11-18 用小黑電腦上的 **ACE-Step 1.5**（AI 作曲模型，MIT 授權，turbo 模型）生成，只用文字描述與段落結構（前奏、主歌、副歌、橋段、尾聲），沒有參考或取樣任何現有歌曲。
- 生成後只做音量標準化、頭尾淡入淡出，再轉成 MP3。
- 播放程式在 `ui/music.js`：右下角 ♪ 按鈕可開關、跳下一首、調音量（設定記在瀏覽器裡），面板會顯示目前的時代與曲名。瀏覽器規定玩家先點一下畫面才能出聲。
- 音樂只是介面效果，不讀寫任何模擬數值。
